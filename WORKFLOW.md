# Research Workflow

This workflow is intentionally lightweight. It should change when the work teaches us that it should change.

## Basic loop

```text
Observation
  -> Question
  -> Evidence
  -> Concepts
  -> Working synthesis
  -> Open questions
  -> Revision
```

## Research object types

These labels describe epistemic status, not importance.

| Type | Prefix | Meaning |
|---|---:|---|
| Observation | OBS | A reported or noticed phenomenon |
| Question | Q | A question worth investigating |
| Source | SRC | A paper, book, article, dataset, or other evidence source |
| Concept | CON | A term or construct under investigation |
| Hypothesis | H | A possible explanation that is not yet established |
| Model | MODEL | A structured explanatory representation |
| Synthesis | SYN | A provisional integration of evidence |
| Research debt | DEBT | Known weakness, gap, or follow-up obligation |

## Epistemic labels

Use these labels freely:

- Observation
- Evidence
- Hypothesis
- Speculation
- Synthesis
- Unknown
- Contradicted
- Needs review

## Minimum useful research node

A useful node should answer:

1. What are we asking?
2. Why are we asking it?
3. What evidence do we currently have?
4. What concepts does it touch?
5. What is still unknown?
6. What would change our mind?

## Hidden-commitment check

Before creating a major artifact, ask:

- Are we assuming the output should be prose?
- Are we assuming a taxonomy before evidence supports it?
- Are we privileging academic literature when another evidence type is relevant?
- Are we confusing communication format with understanding?
- Are we turning a personal observation into a universal claim?

## Commit guideline

Prefer small commits that represent one conceptual move.

Good commit messages:

- Add first research question on delayed comprehension
- Separate observation from ADHD-specific hypothesis
- Add source map for mental model lineage
- Introduce concept stub for external cognition

Avoid:

- update
- notes
- stuff
