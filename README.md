# Codex Method

A research project investigating how deep understanding develops: how information becomes organized, how mental models form, and how those models become useful for explanation, prediction, transfer, and intuition.

This repository begins from personal observation but does not treat personal observation as proof. The working practice is to separate observation, evidence, hypothesis, speculation, and synthesis.

## Working orientation

We are not trying to prove a theory. We are trying to build an evidence-linked map of how understanding develops.

Initial loop:

```text
Observation
  -> Question
  -> Evidence
  -> Concepts
  -> Working synthesis
  -> Open questions
  -> Revision
```

## Early principle

Build the smallest artifact that can teach us something real.

## Research posture

- Strong opinions, lightly held.
- Follow the evidence, especially when it surprises us.
- Treat models as tools, not identities.
- Make hidden commitments visible.
- Prefer cumulative understanding over volume.
